## 一、目前狀態（一段話）

改用與 SOTA 論文一致的 episode-level 協定後，CLIP-LoRA baseline 能重現，但 FeatureSR 的增益幾乎消失。CC-CDFSL 無法從論文重現；ATHA 官方程式碼的 baseline 能重現（ISIC 5-shot 51.83 vs 論文 51.10），但 ATHA 本身宣稱的增益無法重現。使用者決定**繼續做 FeatureSR**，改成讓它進入分類路徑（見第三節）。

## 二、FeatureSR 目前沒效的原因（新設計的出發點）

1. **分類只用 CLS token**。FeatureSR 產生的 28×28 patch 特徵推論時完全不會用到，訓練時只能透過 cycle loss 與 $\mathcal{L}_{CR}$ 間接作用。
2. **cycle loss 幾乎不提供有用梯度**：T-I-T 兩次 argmax 後沒有影像端梯度（舊協定下 λ1 從未作用）；CC-CDFSL 在對齊協定下增益 ≈ 0。FeatureSR 等於接在一條沒通電的線上，這也是 refiner、56×56 都沒效的根本原因。
3. **上採樣器沒有新資訊**：bilinear＋卷積只是把 14×14 的資訊攤開，沒有任何像素層級的新資訊進來。

## 三、接下來要做的事（依序，每一步都與前一步在相同 episode 上配對比較）

所有實驗都用 `train_episodic.py`（乾淨、可斷點續跑、每個 episode 種子只由 (seed, episode 編號) 決定）。先跑 **ISIC、EuroSAT 的 5-shot**（先前 $\mathcal{L}_{CR}$ 有反應的兩個），1-shot 很便宜可以一起跑。4090 上 5-shot 每組約 2.7 小時（500 步）。

### 步驟 0：修正類別名稱，驗證框架（最優先）

- **問題**：ISIC 類別名稱是縮寫（`MEL`、`NV`、`BCC`、`AKIEC`、`BKL`、`DF`、`VASC`），prompt 變成「a photo of a MEL」；EuroSAT 是黏在一起的寫法（`SeaLake`、`AnnualCrop`…）。
- **做法**：在產生 prompt 的地方（`models/clip_wrapper.py` 的 `encode_text` 預設路徑）加一份「資料集 → 顯示名稱」對照，名稱直接沿用 ATHA `coop_lora_trainer.py` 裡寫死的 `label_names`（ISIC："Melanoma"、"Melanocytic Nevus"、"Basal Cell Carcinoma"、"Actinic Keratosis"、"Benign Keratosis"、"Dermatofibroma"、"Vascular Lesion"；EuroSAT："Annual Crop Land"、"Forest"、"Herbaceous Vegetation Land"、"Highway or Road"、"Industrial Buildings"、"Pasture Land"、"Permanent Crop Land"、"Residential Buildings"、"River"、"Sea or Lake"；ChestX 與 CropDiseases 原本就是完整名稱）。類別順序已驗證與我們的資料集一致。
- **注意**：結果檔名（tag）要加上能區分新舊名稱的標記，避免續跑機制把舊結果當成已完成。
- **驗證標準**：ISIC 5-shot baseline 應從 47.71 升到約 50.7–51.8（論文 CLIP-LoRA 50.68；ATHA 程式碼 51.83）。若名稱修正後仍明顯偏低，再考慮把 `train_episodic.py` 的設定改成 ATHA 程式碼實際用的（r=16/α=8、100 步、logit scale 5-shot 4 / 1-shot 2、CoOp 可學習 prompt、無 cosine 排程）。
- **順帶**：用一組對照確認 Prompt Ensemble 過去的增益有多少其實來自名稱展開（`utils/prompt_templates.py` 已把縮寫展開成描述性名稱）。

### 步驟 1：patch 層級分類分數（不做 SR）— 篩選點

讓 patch 特徵進入分類路徑：

```
local_c = mean( top-k_p ( patch_p · T_c ) )        # patch 已 ln_post + proj + L2 normalize，k 取 P 的約 10%
logits  = logit_scale · ( CLS · T  +  γ · local )   # γ 先固定 1.0，再試可學習純量
```

CE 用融合後的 logits 訓練；推論也用融合後的 logits。與步驟 0 的 baseline 做配對比較。
**若 14×14 的 patch 分數都沒有增益，就停在這裡，不必做後面的步驟。**

### 步驟 2：FeatureSR 進入分類路徑

同步驟 1，但 patch 改用 FeatureSR（refiner=0、scale=2，即 28×28）上採樣後的特徵做 top-k 聚合，由 CE 端到端訓練；$\mathcal{L}_{CR}$ 以 λ3=0.3 保留一組、λ3=0 一組。與步驟 1 做配對比較，回答「上採樣本身有沒有增益」。

### 步驟 3：圖像引導的上採樣器

把 bilinear＋卷積的 Upsampler 換成**凍結的 AnyUp**（encoder 無關、不需重訓；arXiv 2510.12764）快速測試，再視結果考慮 JAFAR 式可訓練版本（約 0.7M 參數）。安裝方式與 CLIP 512 維投影後特徵的相容性需先確認。
