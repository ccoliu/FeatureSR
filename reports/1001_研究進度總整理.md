# 研究進度總整理（2026-10-01）

給指導教授的進度報告，整理 9/24 以來的發現。細節見各專題報告（文末列表）。

## 一、摘要

1. **評估協定已與 SOTA 論文對齊**（episode-level fine-tuning）。CLIP-LoRA baseline 在 8 組設定上都在誤差內重現論文數字。過程中修正了一個影響所有實驗的類別名稱 bug（ISIC +2.15）。
2. **兩篇 SOTA 方法的宣稱增益都無法重現**：CC-CDFSL 的公式照字面實作不可行（T-I-T 無梯度、MLP 坍縮），ATHA 官方程式碼只重現約四分之一的增益，而單純的資料增強（+3.15）就比兩者都大。
3. **原本的 FeatureSR 沒有效果，原因已經找到**：分類只用 CLS，patch 特徵根本沒進入分類路徑；而 learned 上採樣器（592 萬參數、每個 episode 隨機初始化）在進入分類路徑後反而會破壞訊號。
4. **新的有效設計**：把 patch 層級的局部分數加入分類，配合 (a) MaskCLIP 式的 value patch、(b) CLS 與 local 分開監督。5-shot 在 4 個資料集中有 3 個得到真實增益（ISIC +1.70、ChestX +0.59、CropDiseases +0.43；EuroSAT 無變化）。
5. **但在較強的 baseline 上，局部分數沒有增益**（10/2 補充）：在 ATHA 官方程式碼的 baseline（有增強，ISIC 5-shot 55.52）上，加入局部分數 **−2.41 ± 0.59**；只在推論時融合（不參與訓練）也是 −0.34 ± 0.23。後續診斷排除了融合方式、文字特徵、資料增強、local 的 logit scale 等原因，並發現增益其實來自 local 監督訓練出的第二個分類頭。見第五之一節。
6. **「特徵上採樣」沒有帶來增益**：learned 上採樣器會破壞訊號；純 bilinear 時正時負，在 ISIC 上等同於平滑；凍結的圖像引導上採樣器 AnyUp（SOTA）與 bilinear 在三個資料集上都沒有差別（±0.1 以內）。

**需要討論的事**：論文定位（第七節）。局部分數的增益在較強的 baseline 上消失，方法本身的貢獻有限；建議改為「嚴謹評估與分析」型的論文。

## 二、評估方法

- **協定**：每個測試 episode 從預訓練 CLIP 重新開始，只用該 episode 的 support set 微調 LoRA 500 步，再分類 query。1-shot 100 個 episode、5-shot 400 個，5-way、15 query。
- **比較方式**：所有方法在**完全相同的 episode** 上執行（每個 episode 的亂數種子只由 seed 與編號決定），回報**逐 episode 配對差 ± 95% CI**；以配對 CI 不含 0 判定為真實效果。
- **超參數全部事先固定**（γ=1、λ=1、k=10%），沒有在測試 episode 上調整。

## 三、Baseline 與類別名稱修正

prompt 原本直接用資料夾名稱（「a photo of a MEL」），改為完整名稱（「a photo of a Melanoma」，與 ATHA 官方程式碼相同）：

| CLIP-LoRA | 5-shot | 論文 | 1-shot | 論文 |
|:---|:---:|:---:|:---:|:---:|
| ISIC | 49.86（縮寫名稱 47.71，**+2.15 ± 0.63**） | 50.68 | 34.33（**+2.16 ± 1.23**） | 35.23 |
| EuroSAT | 92.44（+0.02 ± 0.27） | 92.63 | 82.20（−0.31 ± 0.98） | 81.49 |
| CropDiseases | 95.54 | 96.20 | 81.73 | 85.11 |
| ChestX | 25.36 | 24.44 | 22.57 | 21.73 |
| 平均 | 65.80 | 65.99 | 55.21 | 55.89 |

## 四、主要方法：patch 層級局部分數

```
local_c = mean( top-k ( patch_p · T_c ) )          # 每個類別取相似度最高的 10% patch 的平均
訓練：loss   = CE(s · CLS·T) + λ · CE(s · local)    # 分開監督，λ = 1
推論：logits = s · (CLS·T + γ · local)               # γ = 1
```

patch 用 **value patch**：CLIP 最後一層的 patch 只取 value → out_proj，不經 attention 混合與殘差（MaskCLIP 的做法）；CLS 不受影響。

### 結果（5-shot，− baseline 為配對差，粗體 = CI 不含 0）

| | baseline | 本方法 | − baseline |
|:---|:---:|:---:|:---:|
| ISIC | 49.86 | 51.56 | **+1.70 ± 0.53** |
| ChestX | 25.36 | 25.95 | **+0.59 ± 0.52** |
| CropDiseases | 95.54 | 95.97 | **+0.43 ± 0.21** |
| EuroSAT | 92.44 | 92.38 | −0.06 ± 0.26 |
| 平均 | 65.80 | 66.47 | +0.67 |

1-shot 大多在雜訊內（平均 +0.23；僅 CropDiseases +1.07 ± 0.96 剛好過門檻）。

增益集中在**局部病灶型資料**（皮膚病灶、胸腔異常、葉片病斑）；EuroSAT 的類別由整張圖的紋理決定且已接近天花板，局部分數無幫助。

### 兩個設計都有消融證據（ISIC 5-shot）

| 設計 | 去掉之後 | 證據 |
|:---|:---|:---|
| 分開監督 | 改用融合 logits 訓練：8 組全部變差（−0.2 ~ −1.4），只用 CLS 的準確率全面退化（EuroSAT 最嚴重 92.44 → 79.83） | 融合訓練讓模型只靠一條路壓低 loss，另一條沒被訓練好 |
| value patch | 改用最後一層原始 patch：增益消失（+0.11 ± 0.48）；value − plain = **+1.58 ± 0.50** | 最後一層原始 patch 與文字的局部對齊很差，與 MaskCLIP 系列文獻一致 |

另外試了 3×3 平滑後再取 top-k：ISIC **+0.45 ± 0.39**（51.56 → 52.00），但 ChestX **−0.48 ± 0.41**、CropDiseases +0.07 ± 0.14，效果依資料集而定，因此**主要設定不做平滑**。

## 五、特徵上採樣（原 FeatureSR 主軸）

在第四節的設定上，把 patch 換成上採樣後的特徵：

| 5-shot | − 14×14（配對） |
|:---|:---:|
| ISIC：learned 上採樣器（原 FeatureSR，λ3=0.3 / 0） | **−1.38 ± 0.58** / **−1.40 ± 0.58** |
| ISIC：純 bilinear 28×28 | **+0.30 ± 0.29** |
| ChestX：純 bilinear 28×28 | **−0.42 ± 0.35** |
| CropDiseases：純 bilinear 28×28 | **+0.15 ± 0.10** |
| ISIC：14×14 + 3×3 平滑（無上採樣） | **+0.45 ± 0.39**（與 bilinear 相比 +0.15 ± 0.32，無差異） |

- **learned 上採樣器會破壞訊號**：約 592 萬參數、每個 episode 從隨機初始化訓練（只有 25 張影像），其位置編碼一開始就是長度約 0.45 的隨機向量，加在長度為 1 的 patch 特徵上。$\mathcal{L}_{CR}$ 的權重 λ3 完全不影響結果。
- **純 bilinear 的效果時正時負**，而且在 ISIC 上，14×14 只做平滑就達到相同效果——bilinear 插值不帶來新資訊，其好處等同於較平滑的池化。
- **AnyUp 也沒有幫助**（arXiv 2510.12764，凍結的圖像引導上採樣器，88 萬參數，訓練資料包含 CLIP ViT-B 特徵）。它能從原始影像引入像素層級資訊，是唯一可能讓上採樣帶來新資訊的做法。推論時在同一個模型上比較（模型以平滑 14×14 訓練）：

| 5-shot（同模型配對） | AnyUp 28 − 平滑 14×14 | AnyUp 56 − 平滑 14×14 | AnyUp 28 − bilinear 28 |
|:---|:---:|:---:|:---:|
| ISIC | **−0.20 ± 0.17** | **−0.20 ± 0.17** | +0.09 ± 0.12 |
| ChestX | +0.08 ± 0.18 | +0.11 ± 0.17 | −0.04 ± 0.14 |
| CropDiseases | −0.01 ± 0.08 | +0.00 ± 0.08 | +0.01 ± 0.06 |

  AnyUp 的輸出與 bilinear 確實不同（平均餘弦約 0.91），但分類結果沒有差別。限制：訓練時沒有經過 AnyUp；但 bilinear 在訓練時用過（上表）同樣沒有超過 14×14，而 AnyUp 與 bilinear 幾乎相同，訓練時也經過 AnyUp（成本 4–6 倍）預期不會改變結論。

## 五之一、在較強 baseline 上的驗證（10/2）

ATHA 官方程式碼的 CLIP-LoRA baseline（CoOp 可學習 prompt、r=16、logit scale 4、100 步、5 倍資料增強）比我們的 baseline 強約 5 分。在其上加入同樣的局部分數（value patch、分開監督、λ=1、γ=1、k=10%），ISIC 5-shot，400 個 episode 配對（修改後的程式碼可固定 episode 序列，見 `scripts/atha_local.patch`）：

| | λ=1（local 參與訓練） | λ=0（只在推論時融合） |
|:---|:---:|:---:|
| 融合後 − baseline（55.52） | **−2.41 ± 0.59** | **−0.34 ± 0.23** |
| 只用 CLS − baseline | **−2.23 ± 0.59** | −0.18 ± 0.22 |
| 只用 local（平均） | 52.87 | 51.36 |
| 融合 − 同模型只用 CLS | **−0.18 ± 0.12** | −0.16 ± 0.17 |

- local 參與訓練會拉低 CLS（λ=0 時 CLS 不受影響，可確認是訓練干擾）。
- 但即使沒有干擾，融合也沒有增益：局部分數在這個設定下沒有補充資訊。
**後續診斷（10/2，皆為 ISIC 5-shot、同一批 episode 配對）**：

1. **推論時的各種訊號都沒有互補性**。在 ATHA baseline 上存下特徵、離線比較 9 種訊號 × 7 種融合（patch 對文字〔CoOp / 固定 prompt〕、DN4 式 query patch 對 support patch、support 原型；直接相加 / 標準化後相加），開發集（seed 2，100 個 episode）上最好的只有 +0.19 ± 0.31。局部訊號與 CLS 的預測有 78–85% 相同，意見不同時 CLS 對的較多；support 原型與 CLS 有 99.3% 相同。CoOp 學到的文字與固定 prompt 的餘弦相似度 0.997，文字特徵不是原因。
2. **不是資料增強造成的**。無增強的 ATHA baseline（51.89）上做同樣的分析，結果相同（最好 +0.07 ± 0.19，18 個融合設定顯著變差）。
3. **增益的來源是 local 監督訓練出的第二個分類頭，而不是 value patch 本身**：

| n=100 | 融合 − baseline | 只用 CLS − baseline | 只用 local | 融合 − 同模型只用 CLS |
|:---|:---:|:---:|:---:|:---:|
| 我們的框架 λ=1 | +0.65 ± 1.06 | −0.11 ± 1.02 | 50.69 | **+0.76 ± 0.61** |
| 我們的框架 λ=0（只在推論融合） | **−5.28 ± 1.22** | −0.25 ± 0.61 | 33.61 | **−5.03 ± 1.06** |
| ATHA 無增強 λ=1，local scale 4 | **−2.45 ± 1.21** | **−2.52 ± 1.19** | 49.37 | +0.07 ± 0.26 |
| ATHA 無增強 λ=1，local scale 100 | **−2.97 ± 1.17** | **−2.91 ± 1.16** | 47.27 | −0.07 ± 0.27 |

   在我們的框架中，未經訓練的 local 分支幾乎無用（33.61），λ=1 把它訓練成與 CLS 相當的分類頭，兩者互補。方法的本質較接近「共用 backbone、不同彙整方式的兩個分類頭的 ensemble」。在 ATHA 上，訓練第二個分類頭會拉低 CLS（與 local 的 logit scale 無關），且兩者沒有互補性；推測與 ATHA 的 r=16 LoRA、CoOp 有關，尚未拆開驗證。

**結論：局部分數只在較弱的 baseline 上有幫助**——與 ATHA 自身增益的命運相同：資料增強（+3.15）就足以吃掉幾個百分點的方法增益。

## 六、可重現性發現

| 項目 | 發現 | 證據 |
|:---|:---|:---|
| 「100 epochs」的歧義 | 5-way 下 support 小於 batch，照字面只有 100 步，嚴重訓練不足（ISIC 5-shot 31.98 vs 論文 50.68） | 配對實驗：100 → 500 步 +17 ~ +18 |
| CC-CDFSL 的 T-I-T（Eq. 7–9） | 兩次 argmax 後影像端沒有梯度 | 梯度驗證 |
| CC-CDFSL 的 I-T-I + MLP（Eq. 5, 13–15） | MLP 坍縮成常數輸出（兩兩餘弦 0.99），loss 被平凡降到 0 | 實測 |
| CC-CDFSL 增益 | 對齊協定下 +0.04 ~ +0.52（論文 +2.9 ~ +4.6） | 5 組配對實驗 |
| ATHA 官方程式碼 | README 指令漏掉 `-method ours`；有一個會直接報錯的 bug；評估時沒有 `no_grad` 導致 OOM | 已做成 patch |
| ATHA 增益（ISIC 5-shot） | 無增強 +1.26 ± 0.66、有增強 −0.42 ± 0.63（論文 +5.32）；單純資料增強就有 +3.15 | 配對實驗 |
| 類別名稱 | 縮寫名稱讓 ISIC 低約 2 分 | 配對實驗 |

## 七、建議的論文定位與下一步

**建議定位（10/2 修正）**：局部分數在較強的 baseline 上沒有增益（第五之一節），不適合單獨作為方法貢獻。建議改為「嚴謹評估與分析」型的論文，可能的章節：
1. **評估方法**：episode-level 協定對齊、逐 episode 配對評估；本研究中好幾個看似有效的增益（FeatureSR、bilinear 上採樣、局部分數）都是靠配對比較與對照組才分辨出來的。
2. **可重現性**（第六節）：兩篇 SOTA 的宣稱增益都無法重現。
3. **局部分數**：在標準 CLIP-LoRA 上有效且有完整消融（分開監督、value patch），但增益會被更強的 baseline 吃掉。
4. **特徵上採樣**：learned、bilinear、SOTA 的 AnyUp 在 few-shot CDFSL 下都不帶來增益；learned 上採樣器因參數量與隨機初始化而有害。

共同的結論：這個 benchmark 上幾個百分點的方法增益相當脆弱，取決於 baseline 的強弱與評估方式。

**下一步（待與教授討論後決定）**：
1. 論文定位。
2. 若採分析型定位：把上面第 3 章的「增益被強 baseline 吃掉」（第五之一節）延伸到其他資料集（ATHA 程式碼每組約 3.8 小時），以及 ATHA 自身在其他資料集的重現。
3. 資料池與 BSCD-FSL 標準不一致（CropDiseases 用 Augmented 版、ChestX 張數偏多），影響絕對數字，是否更換待決定。
