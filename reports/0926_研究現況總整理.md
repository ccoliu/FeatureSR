# 研究現況總整理（2026-09-26）

從「找技術相近的論文」開始，一路查到評估協定、基準方法可重現性、資料本身的問題。這份文件把目前確定的事、還不確定的事、以及正在進行的實驗整理在一起。細節見各專題報告。

## 一、一句話現況

**我們先前所有的主表數字，都是在一個跟 SOTA 論文不同、且較弱的協定下量的；改用對齊的協定後，FeatureSR 的增益幾乎消失，而我們原本當作基礎的 CC-CDFSL 無法從論文重現。** 目前正在 4090 上跑 ATHA（ICML 2026）的官方程式碼，目標是取得一個可驗證的 SOTA 對照和實驗框架。

## 二、已確定的發現

### 1. 評估協定不一致（最根本的問題）

CC-CDFSL、ATHA 等 SOTA 論文用的是 **episode-level fine-tuning**：每個測試 episode 都從預訓練 CLIP 重新開始，只用該 episode 的 support set 微調，再分類 query。我們原本是在固定 pool 上訓練一次，評估時完全不用 support。兩者的數字不能並列比較。

新增 `train_episodic.py` 實作對齊協定（CLIP-LoRA 官方超參數、每個 episode 重置 LoRA、支援斷點續跑、每個 episode 種子固定可配對比較）。

### 2. 「100 epochs」照字面解讀會嚴重訓練不足

5-way 下 support 小於 batch size，1 epoch = 1 步。只用 100 步時，ISIC 5-shot 只有 31.98%（論文 50.68%），訓練 CE 接近隨機。配對診斷：100→500 步提升 +17~18 分，500→2500 步在 ISIC 無差異、CropDiseases 還有 +1.8。決定統一用 500 步。

500 步下 CLIP-LoRA baseline 8 組中有 6 組在誤差內對上論文，**ISIC 兩個 shot 都低約 3 分**（見第 5 點，類別名稱很可能是主因）。→ `reports/0924_Episodic協定對齊報告.md`

### 3. CC-CDFSL 無法從論文描述重現

在對齊協定下，我們實作的 CC-CDFSL 相對 baseline 的增益只有 +0.04 ~ +0.52，論文報告 +2.9 ~ +4.6。比對論文公式後發現三處偏差，並且照公式字面重寫也行不通：

| 照論文公式字面實作 | 結果 |
|:---|:---|
| T-I-T（Eq. 7–9） | 兩次 argmax 後 loss 只剩文字特徵，影像端拿不到梯度 |
| I-T-I + MLP（Eq. 5, 13–15） | MLP 坍縮成常數輸出（兩兩餘弦 0.99），loss 被平凡降到 0 |
| 官方程式碼 github.com/z-yaz/CC-CDFSL | 只有 README 和海報 |

**對過去實驗的影響**：舊 `train.py` 的文字特徵在 `no_grad` 下計算，`L_TIT` 完全沒有梯度，**λ1 在所有舊實驗中都沒有作用**。我們一直稱為「CC-CDFSL」的，實際上只有 CE + λ2·I-T-I。

已寄信給第一作者詢問三個具體問題（訓練步數、T-I-T 梯度路徑、MLP 如何避免坍縮），期望不高。

### 4. FeatureSR 在對齊協定下的效果

| | +FSR − baseline |
|:---|:---:|
| ISIC 1-shot | +0.72 ± 0.93 |
| EuroSAT 1-shot | +0.24 ± 0.74 |
| CropDiseases 1-shot | +0.44 ± 0.74 |
| ChestX 1-shot | +0.23 ± 0.76 |
| ISIC 5-shot | +0.51 ± 0.45 |

除了 ISIC 5-shot 勉強不含 0，其餘都在雜訊內（5-shot 其他資料集已停止未跑）。需要注意，FeatureSR 只能透過 cycle loss 影響訓練，而我們的 cycle loss 本身殘缺，所以這還不是「FeatureSR 在正確基準上」的最終答案。另外，CLIP-LoRA 分類只用 CLS token，任何只改 patch 特徵的方法都只能間接起作用。

### 5. 類別名稱 bug（影響所有實驗）

ISIC 的類別名稱是縮寫（`MEL`、`NV`、`BCC`…），prompt 變成「a photo of a MEL」；EuroSAT 是黏在一起的寫法（`SeaLake`、`AnnualCrop`）。ATHA 程式碼用的是完整名稱（"Melanoma"、"Sea or Lake"）。

而我們的 Prompt Ensemble 模板裡正好把縮寫展開成描述性名稱，所以**舊協定下 Prompt Ensemble 的增益（EuroSAT +3.64、ISIC +0.73），很可能有相當部分來自「修正了類別名稱」而不是「模板集成」**，需要一組對照實驗確認。

### 6. 資料池與 BSCD-FSL 標準不一致

| | 我們 | BSCD-FSL 標準 |
|:---|:---:|:---:|
| ISIC | 10,015 | 10,015 |
| EuroSAT | 27,000 | 27,000 |
| CropDiseases | **70,295**（Kaggle「Augmented」版） | 約 43,000 |
| ChestX | **31,338** | 約 25,848（只保留單一標籤） |

CropDiseases 的 Augmented 版是離線增強過的影像，support 與 query 之間可能出現同一張原圖的增強副本；ChestX 可能混入多標籤影像。會影響絕對數字。

## 三、ATHA 官方程式碼（正在 4090 上重現）

ATHA（github.com/shuaiyi308/ATHA）有完整程式碼，其 CLIP-LoRA baseline 平均與 CC-CDFSL 論文相同（5-shot 皆為 65.99%），看起來是同一套協定。從程式碼確認的實際設定：

| 項目 | ATHA 程式碼 | 論文寫的 / 我們原本推測 |
|:---|:---|:---|
| 每個 episode 步數 | 100（`total_epoch=100`, `batch_size=9999`） | 我們改成 500 |
| LoRA | r=16, α=8，視覺＋文字 q/k/v | CLIP-LoRA 官方 r=2 |
| 文字端 | LoRA **＋ CoOp 可學習 prompt** | 論文稱「CLIP-LoRA」 |
| Logit scale | 5-shot 4、1-shot 2 | CLIP 原本 100 |
| 學習率排程 | 無 | cosine |
| 1-shot episode 數 | 800 | 100 |
| 啟用 ATHA | 需 `-method ours`（**README 指令漏掉了**） | — |
| 初始化 | α 在第 7 層 0.8、β=0 | 論文寫第 8 層、β=0.01 |
| ratio | README 只給 ISIC：add 0.3 / minus 0.2 | 論文寫 0.1 / 0.1 |

官方程式碼有一個會直接報錯的 bug（`Transformer.forward` 多傳了未定義參數），已做成 `scripts/atha_fix_return_similarity.patch`。本機 3060 驗證第一個 episode 可正常執行（ISIC 5-shot 62.67%），第二個 episode 因每個 episode 重建一份 CLIP、顯存不足而 OOM，正式重現交給 4090。

**重現目標**：

| | Crop | EuroSAT | ISIC | ChestX | 平均 |
|:---|:---:|:---:|:---:|:---:|:---:|
| baseline 5-shot | 96.21 | 92.52 | 51.10 | 24.13 | 65.99 |
| ATHA 5-shot | 97.62 | 93.41 | 56.42 | 26.67 | 68.53 |
| baseline 1-shot | 85.32 | 81.41 | 35.23 | 21.73 | 55.92 |
| ATHA 1-shot | 87.99 | 82.56 | 38.86 | 24.00 | 58.35 |

腳本 `scripts/run_atha_repro.sh` 先跑 5-shot、ISIC 最前面。**ISIC 5-shot 的 baseline 和 ATHA 跑完就先檢查**，接近 51.10 / 56.42 才讓它繼續跑完。

## 四、對過去結論的影響

| 過去的結論 | 現在的狀態 |
|:---|:---|
| FeatureSR 在 5-shot 平均 +1.02~1.15% | 只在舊協定下成立；對齊協定下幾乎都在雜訊內 |
| 「以 CC-CDFSL 為基礎」 | λ1 從未作用，實際只有 CE + λ2·I-T-I |
| Refiner 無效、56×56 無效、λ3 依資料集而定 | 內部消融結論，在舊協定下仍然成立，但不能外推到對齊協定 |
| Prompt Ensemble 有效 | 增益可能主要來自類別名稱修正，待驗證 |
| 5-shot baseline：CropDiseases 89.68、ISIC 41.44 | 對齊協定下是 95.54、47.71；舊數字不能放進 SOTA 比較表 |

## 五、待決定 / 待辦

1. **看 ATHA 重現結果**（進行中）。重現成功 → 以 ATHA 程式碼為實驗框架；失敗 → 找出剩下沒對齊的部分。
2. **修正類別名稱**，並用一組對照確認 Prompt Ensemble 的增益有多少來自名稱修正。
3. **資料池**：評估是否改用 BSCD-FSL 標準版本的 CropDiseases 和 ChestX。
4. **論文定位**（建議跟教授討論）：原本「在 CC-CDFSL 上加 FeatureSR」的敘事已經站不住。可能的方向：
   - 在已驗證的框架上找真正有效的改進。token 層級的方法（例如 ATHA 那類直接影響 CLS 的做法）比只改 patch 的方法更有機會。
   - 把這次整理出的重現性問題寫成論文的一個章節（「100 epochs」的歧義、T-I-T 不可微、MLP 坍縮、README 漏參數、類別名稱）。每一項都有配對實驗或程式碼證據。
5. 等 CC-CDFSL 作者回信。
