# Test-Time Augmentation（TTA）獨立驗證報告
# 最後更新：2026-09-01

## 背景

`train.py` / `evaluate.py` 都預留了 `--use_tta` 開關（水平翻轉 + 原圖特徵平均融合，`encode_image_with_patches` 對原圖與 `torch.flip(images, dims=[-1])` 各跑一次，正規化後取平均再重新正規化）。

早期探索（`logs/enhanced_5shot_real.log`，2026-08-26）曾對 TTA 做過一輪測試，4 個資料集平均 delta 只有 **-0.23%**，看起來像是「TTA 對這個任務沒用」。但那批測試使用的 checkpoint 正是後來被診斷出「訓練/測試 prompt 分布不一致」的壞掉版本（見 [`reports/0829_PromptEnsemble修復報告.md`](0829_PromptEnsemble修復報告.md)）——TTA 從未在「校準過的模型」上被獨立驗證過，此前的負面結論建立在噪聲基礎上，需要重新測試才能下定論。

## 驗證方法

在兩種已修復、ensemble-aware 訓練出來的 checkpoint 上，各自單獨開關 `--use_tta`（`--use_prompt_ensemble` 恆定開啟，避免與 §0829 修復的問題混淆），5-way 5-shot、400 episodes、`seed=42`：

- `checkpoints_ensemble/`：僅 Prompt Ensemble
- `checkpoints_fsr_ensemble/`：Feature-SR + Prompt Ensemble（目前最佳模型）

腳本：`scripts/test_tta_isolated.sh`、`scripts/test_tta_isolated_fsr.sh`，log 存於 `logs/tta_check/`。

## 結果

### Ensemble-only checkpoint + TTA

| 資料集 | 無 TTA | 有 TTA | Delta |
|:---|:---:|:---:|:---:|
| EuroSAT | 93.69 ± 0.32% | 93.97 ± 0.30% | +0.28% 📈 |
| CropDiseases | 90.61 ± 0.62% | 90.96 ± 0.62% | +0.35% 📈 |
| ISIC 2018 | 44.10 ± 0.64% | 44.03 ± 0.64% | -0.07%（誤差範圍內持平）|
| ChestX | 22.77 ± 0.49% | **23.60 ± 0.49%** | **+0.83%** 📈 |
| **平均** | **62.79%** | **63.14%** | **+0.35%** 📈 |

### Feature-SR + Ensemble checkpoint + TTA

| 資料集 | 無 TTA | 有 TTA | Delta |
|:---|:---:|:---:|:---:|
| EuroSAT | 94.00 ± 0.32% | 94.36 ± 0.32% | +0.36% 📈 |
| CropDiseases | 90.28 ± 0.68% | **91.44 ± 0.60%** | **+1.16%** 📈 |
| ISIC 2018 | 44.13 ± 0.67% | **42.75 ± 0.69%** | **-1.38%** ⚠️ |
| ChestX | 22.59 ± 0.45% | 23.19 ± 0.46% | +0.60% 📈 |
| **平均** | **62.75%** | **62.94%** | +0.19% 📈 |

## 分析

1. **TTA 本身沒有問題，之前的負面結論是被壞 checkpoint 汙染的。** 在校準過的模型上，EuroSAT / CropDiseases / ChestX 三個資料集於兩種模型組態下都一致正向，且多數 delta 超出信賴區間範圍（例如 ChestX +0.83%、CropDiseases +1.16%），不是雜訊。
2. **ChestX 的增益特別值得注意**：+0.83%（ensemble-only）與 +0.60%（FSR+ensemble）都大於 Feature-SR 或 Prompt Ensemble 單獨在 ChestX 上的增益（分別是 +0.03% 與 -0.09%／+0.08%），顯示 TTA 是目前對 ChestX 這個「backbone 天花板」資料集最有效的單一手段。
3. **ISIC 是唯一的例外**：Ensemble-only 上持平（-0.07%，在誤差範圍內），但疊加 Feature-SR 後 TTA 反而讓 ISIC 掉了 **-1.38%**，超出雙邊信賴區間之和（0.67% + 0.69% = 1.36%），是統計上站得住腳的負面效果，而非雜訊。合理解釋：ISIC 皮膚病灶分類理論上對水平翻轉是不變的，但 Feature-SR 已經把視覺特徵校準得更緊（ISIC 本身在 Feature-SR 上的增益就偏小，見 `0831` 報告），此時再疊加一層 test-time 特徵平均，反而稀釋掉原本已經很精細的判斷邊界。

## 結論與建議

TTA **不應該全域開關**，而應依資料集決定：

| 資料集 | 建議 |
|:---|:---:|
| EuroSAT | 開啟 |
| CropDiseases | 開啟 |
| ChestX | 開啟（目前對此資料集效果最好的單一手段）|
| ISIC 2018 | **關閉**，尤其搭配 Feature-SR 時 |

這與 ChestX 的「backbone 架構天花板」（`docs/FeatureSR_Methodology.md` §6.1）性質相似，都是「某個增強手段對特定 domain 不普適」的案例，非方法本身失效。
