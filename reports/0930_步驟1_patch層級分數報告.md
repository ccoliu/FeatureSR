# 步驟 1：patch 層級分數進入分類路徑（2026-09-30）

`reports/0928_交接與下一步.md` 第三節步驟 1。所有比較都是與步驟 0 baseline（完整類別名稱，`reports/0928b`）在同一批 episode 上的配對差 ± 95% CI；**粗體 = CI 不含 0**。

## 結論

**value patch ＋ 分開監督，在 5-shot 的 4 個資料集中有 3 個得到真實增益（ISIC +1.70、ChestX +0.59、CropDiseases +0.43），EuroSAT 無變化；1-shot 大多在雜訊內。** 步驟 1 通過篩選，可以進入步驟 2（FeatureSR）。

最終設定：`--local_score --local_k_frac 0.1 --local_gamma 1.0 --patch_mode value --local_loss separate --local_lambda 1.0`（γ、λ、k 皆事先固定，未在測試 episode 上調整）。

## 方法

```
local_c = mean( top-k_p ( patch_p · T_c ) )     # k = 10% × P（14×14 時 k=20）
訓練：loss   = CE(s · CLS·T) + λ · CE(s · local)
推論：logits = s · (CLS·T + γ · local)
```

patch 有兩種取法（`models/clip_wrapper.py` 的 `patch_mode`）：
- **plain**：最後一層的完整輸出經 ln_post + proj。
- **value**（MaskCLIP 式）：最後一層的 patch 只取 value → out_proj，不經 attention 混合、殘差與 MLP，再經 ln_post + proj。CLS 照常走完整的最後一層（已驗證與 plain 完全相同）。LoRA 的 v 增量也包含在內。

## 過程：三輪實驗

### 1. 融合訓練（γ=1）：全部變差

照交接文件原本的設計，用融合 logits `CE(s·(CLS·T + γ·local))` 訓練。8 組沒有一組變好：

| | ISIC 5 | EuroSAT 5 | ISIC 1 | EuroSAT 1 |
|:---|:---:|:---:|:---:|:---:|
| plain | **−0.98 ± 0.48** | **−0.45 ± 0.26** | **−1.39 ± 0.77** | −0.23 ± 0.95 |
| value | −0.22 ± 0.51 | **−1.03 ± 0.31** | **−0.87 ± 0.81** | −1.01 ± 1.18 |

原因：**融合訓練讓 CLS 退化。** 同一個模型只用 CLS 推論，8 組全部低於 baseline，最嚴重的是 EuroSAT 5-shot value（92.44 → 79.83）。兩個分數相加後一起算 CE，模型可以只靠其中一條路把 loss 壓低，另一條路就沒被好好訓練。

### 2. 分開監督（λ=1）：CLS 恢復，ISIC value 出現增益

| 5-shot | − baseline | 只用 CLS − baseline | 融合 − 同模型只用 CLS |
|:---|:---:|:---:|:---:|
| ISIC plain | +0.11 ± 0.48 | +0.25 ± 0.46 | −0.14 ± 0.28 |
| **ISIC value** | **+1.70 ± 0.53** | +0.74 ± 0.49 | **+0.96 ± 0.28** |
| EuroSAT plain | +0.20 ± 0.22 | −0.06 ± 0.21 | **+0.26 ± 0.15** |
| EuroSAT value | −0.06 ± 0.26 | −0.10 ± 0.24 | +0.04 ± 0.17 |

- CLS 回到 baseline 水準，確認問題出在融合訓練。
- ISIC 的增益來自兩部分：local 監督讓 CLS 本身略好（+0.74），推論時融合 local 再加 +0.96（在同一個模型上配對，CI 很窄）。
- **value 是必要的**：ISIC 上 value − plain = **+1.58 ± 0.50**。最後一層原始 patch 與文字的局部對齊很差，與 MaskCLIP 系列文獻的觀察一致。
- γ 診斷（ISIC value，推論時 γ=0.1/0.3/0.5/1 → 50.84/51.14/51.26/51.56）：γ 越大越好，事先固定的 γ=1 不是湊巧選到的。

即本報告開頭的兩張表。

## 判讀

- **5-shot 的增益集中在局部病灶型資料**（ISIC 皮膚病灶、ChestX 胸腔異常、CropDiseases 葉片病斑）。EuroSAT 的類別由整張圖的紋理決定，且已接近天花板，局部分數沒有幫助。這與 top-k patch 聚合的設計動機一致。
- **1-shot 沒有穩定增益。** 可能原因：只有 5 張 support 影像，local 分支學不起來；或 1-shot 只有 100 個 episode，CI 太寬（±0.9），看不出 +0.5 以下的效果。CropDiseases 1-shot 的 +1.07 剛好過門檻，應保守看待。
- **比較基準**：ISIC 5-shot 的 +1.70，大於我們重現 ATHA 時量到的增益（無增強 +1.26、有增強 −0.42）。
- **診斷用的 γ 掃描只用來判斷 γ=1 是否過大**，不能拿來挑主結果；主結果全部是事先固定的 γ=1。

## 下一步：步驟 2（FeatureSR）

在同一套設定（value patch、分開監督 λ=1、γ=1）上，把 patch 換成 FeatureSR（refiner=0、scale=2）上採樣到 28×28 的特徵，由 CE 端到端訓練，λ3=0.3 與 λ3=0 各一組，與本報告的 14×14 結果配對比較，回答「上採樣本身有沒有增益」。程式碼已支援（加 `--use_feature_sr`）。

注意：煙霧測試時，**融合訓練**加 FSR 的單一 episode，只用 CLS 掉到 28%；改成分開監督後需要重新確認 FSR 不會再拖垮 CLS。

建議先跑 ISIC、ChestX、CropDiseases 的 5-shot（有增益的三個）。
